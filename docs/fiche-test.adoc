== 1. Lancement

* [ ] L'application s'ouvre sans erreur

== 2. Menu

=== Menu Prism

* [ ] "À propos de Prism" affiche une boîte de dialogue
* [ ] "Thème clair/sombre" bascule le thème
* [ ] "Mode zen" masque tout sauf l'éditeur

=== Menu Fichier

* [ ] "Nouveau" (Cmd+N) crée un nouveau document vide
* [ ] "Ouvrir…" (Cmd+O) affiche le dialogue macOS et ouvre un .adoc
* [ ] "Ouvrir récent…" ouvre la sidebar
* [ ] "Enregistrer" (Cmd+S) sauvegarde (ou demande un nom si nouveau)
* [ ] "Enregistrer sous…" (Cmd+Shift+S) demande un nouveau nom

=== Menu Édition

* [ ] "Annuler" (Cmd+Z) fonctionne dans l'éditeur
* [ ] "Copier" / "Coller" fonctionnent
* [ ] "Rechercher…" (Cmd+F) ouvre la barre de recherche

=== Menu Insertion

* [ ] "Gras" insère `*...*` autour de la sélection
* [ ] "Italique" insère `_..._` autour de la sélection
* [ ] "Monospace" insère des backticks
* [ ] "Titre 1" / "Titre 2" / "Titre 3" insèrent le bon préfixe
* [ ] "Liste à puces" insère `* `
* [ ] "Liste numérotée" insère `. `
* [ ] "Lien" insère un squelette de lien
* [ ] "Image" insère un squelette d'image
* [ ] "Bloc de code" insère un bloc source
* [ ] "Citation" insère un bloc quote
* [ ] "Tableau" insère un squelette de tableau
* [ ] "Note / Admonition" insère `NOTE: `

=== Menu Affichage

* [ ] "Sidebar" (Cmd+B) affiche/masque la sidebar
* [ ] "Prévisualisation" (Cmd+P) affiche/masque la prévisualisation
* [ ] "Minimap" (Cmd+M) affiche/masque la minimap

=== Menu Export

* [ ] "HTML" (Cmd+E) exporte un fichier .html
* [ ] "PDF" exporte un fichier .pdf
* [ ] "EPUB" exporte un fichier .epub
* [ ] "Tout exporter" (Cmd+Shift+E) exporte les 3 formats
