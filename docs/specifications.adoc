== Vision du projet

Prism est un éditeur AsciiDoc de bureau en pur Crystal, conçu pour offrir une expérience d'écriture et de publication complète : éditer, styler, prévisualiser et exporter ses documents vers HTML, PDF et EPUB depuis une interface native et légère.

=== Principes directeurs

* *Pur Crystal* — le pipeline de conversion repose intégralement sur les shards aloli-crystal
* *Interface native légère* — webview native (WKWebView sur macOS), pas d'Electron ni de serveur HTTP
* *Édition bidirectionnelle* — l'utilisateur peut modifier le source AsciiDoc ou le rendu HTML, les deux restent synchronisés
* *Orienté publication* — export vers les trois formats majeurs (HTML, PDF, EPUB) avec personnalisation du style
* *Intégration Git* — navigation et ouverture de fichiers depuis un dépôt Git

== Contraintes et décisions techniques

=== Édition bidirectionnelle (AsciiDoc ↔ HTML)

La conversion AsciiDoc → HTML repose sur `asciicrystal` qui produit un AST. La difficulté principale est la conversion *inverse* (HTML → AsciiDoc).

Approche envisagée :

. L'AST AsciiDoc est la *source de vérité*
. AsciiDoc → AST → HTML est le flux naturel (asciicrystal)
. HTML modifié → diff avec le HTML original → identification des nœuds AST impactés → mise à jour de l'AST → regénération du source AsciiDoc
. En V0.2, seul le sens AsciiDoc → HTML est actif ; le HTML est en lecture seule éditable
. En V0.3, la conversion inverse est implémentée

=== Intégration Git

Deux approches possibles :

* *libgit2* via des bindings Crystal — plus rapide, pas de dépendance externe, mais bindings à écrire ou trouver
* *CLI git* via `Process.run` — plus simple, dépend de git installé sur le système

Décision reportée à la V0.3. L'approche CLI est plus pragmatique pour commencer.

=== Stockage des préférences

Les préférences utilisateur seront stockées dans un fichier JSON dans `~/.config/prism/` (ou `~/Library/Application Support/Prism/` sur macOS).

== Glossaire

AST:: Abstract Syntax Tree — représentation arborescente du document AsciiDoc après parsing
Webview:: Composant natif du système d'exploitation permettant d'afficher du contenu HTML (WKWebView sur macOS, WebKitGTK sur Linux)
Binding:: Pont de communication entre Crystal et JavaScript via la webview
Shard:: Bibliothèque Crystal (équivalent d'une gem Ruby ou d'un package npm)
